## Computer Aided Drafting, Product Design, & Fabrication
- **3D Modeling**: creating digital three-dimensional representations of objects
- **3D Printing**: building physical objects layer by layer from a digital model
- **3D Rendering**: generating photorealistic images or animations from 3D models
- **BIM (Building Information Modeling)**: intelligent 3D building models that hold design, construction, and operation data
- **Building Energy Modeling**: simulating a building's energy use to evaluate its design and efficiency
    - **LEED (Leadership in Energy and Environmental Design)**: the most widely used green building certification system
    - **VRF (Variable Refrigerant Flow)**: an HVAC system that varies refrigerant flow to heat and cool zones individually
- **CAD (Computer-Aided Design)**: using software to create precise 2D drawings and 3D models
- **Drone Mapping**: turning aerial drone photos into maps and 3D models of a site through photogrammetry
- **FEA (Finite Element Analysis)**: simulating how parts respond to forces, heat, and vibration

## Computer Architecture
- **ISA (Instruction Set Architecture)**: the instructions, registers, and memory model a processor exposes to software
    - **CISC (Complex Instruction Set Computer)**: uses a large and complex set of instructions
        - **x86**: Intel's widely used CPU architecture that powers most personal computers
    - **RISC (Reduced Instruction Set Computer)**: uses a small optimized set of simple instructions
        - **ARM (Advanced RISC Machine)**: power-efficient architecture for smartphones, embedded systems, etc.
        - **MIPS (Microprocessor without Interlocked Pipelined Stages)**: RISC ISA widely used to teach processor design
        - **RISC-V**: an open, royalty-free RISC ISA used in research, education, and a growing range of chips

## Computer Hardware
- **Desktop Tower**: an upright computer case that houses the motherboard, CPU, GPU, storage, and power supply
- **Storage Device**: hardware that stores data persistently
    - **HDD (Hard Disk Drive)**: stores data magnetically on spinning platters; cheap per terabyte but slower
    - **SSD (Solid-State Drive)**: stores data on flash memory with no moving parts; much faster than an HDD

## Embedded Systems
- **Amateur Radio**: licensed, non-commercial use of radio frequencies for communication and experimentation
- **Flight Software**: software that controls spacecraft and other embedded systems in real time
- **GPIO (General-Purpose Input/Output)**: programmable pins that let a board read sensors and control components
- **IoT (Internet of Things)**: physical devices with sensors and software that exchange data over the internet
- **Microcontroller**: a self-contained computer on a single integrated circuit
- **Microprocessor**: a CPU on a single chip that relies on external memory and peripherals
    - **SBC (Single-Board Computer)**: a complete computer built on one circuit board
- **SDR (Software-Defined Radio)**: radio communication where signal processing is done in software instead of hardware

## Quantum Computing
- **Entanglement**: a link between qubits where measuring one immediately determines the state of the other
- **Quantum Circuit**: a sequence of quantum gates applied to qubits, the basic model of a quantum program
- **Quantum SDK**: a toolkit for building, simulating, and running quantum circuits on simulators or real hardware
- **Qubit**: the basic unit of quantum information, which can be in a superposition of 0 and 1
- **Superposition**: a qubit's ability to exist in a combination of states until it is measured

## Scientific Computing
- **GPU Computing**: using a GPU's many cores to accelerate general-purpose parallel computation
- **Numerical Computing**: solving math problems with numeric approximations and algorithms on computers
- **Symbolic Computing**: manipulating mathematical expressions exactly, such as solving equations algebraically
