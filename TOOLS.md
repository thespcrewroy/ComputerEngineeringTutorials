## Computer Aided Drafting, Product Design, & Fabrication
- **3D Modeling**
    - **[Blender](https://docs.blender.org/)**: free, open-source 3D suite for modeling, animation, rendering, simulation, and video editing
    - **[SketchUp](https://help.sketchup.com/)**: 3D modeling for architecture, interiors, engineering, and product design, with a free web version
    - **[TinkerCAD](https://www.tinkercad.com/)**: beginner-friendly online 3D design and electronics simulation for modeling, coding, and 3D printing
- **BIM (Building Information Modeling)**
    - **[Revit](https://help.autodesk.com/view/RVT/2026/ENU/)**: Autodesk's BIM software for building design, free for students
- **Building Energy Modeling**
    - **[eQUEST](https://www.doe2.com/equest/)**: free building energy simulation tool built on the DOE-2 engine
- **CAD (Computer-Aided Design)**
    - **[AutoCAD](https://help.autodesk.com/view/ACD/2026/ENU/)**: Autodesk's CAD software for precise 2D drawings and 3D models, free for students

## Embedded Systems
- **Flight Software**
    - **[F´ (F Prime)](https://nasa.github.io/fprime/)**: NASA JPL's open-source, component-driven flight software framework
- **Microcontroller**
    - **[Arduino](https://docs.arduino.cc/)**: open-source microcontroller platform with easy-to-use hardware and software
    - **[Atmel AVR](https://www.microchip.com/en-us/products/microcontrollers-and-microprocessors/8-bit-mcus/avr-mcus)**: Microchip's 8-bit microcontroller family, used in classic Arduino boards
    - **[Raspberry Pi Pico](https://www.raspberrypi.com/documentation/microcontrollers/pico-series.html)**: a low-cost microcontroller board based on the RP2040 chip
- **Microprocessor**
    - **SBC (Single-Board Computer)**
        - **[Raspberry Pi](https://www.raspberrypi.com/documentation/)**: a low-cost single-board computer for learning programming and building projects
- **SDR (Software-Defined Radio)**
    - **[GNU Radio](https://wiki.gnuradio.org/)**: free software development framework that provides signal processing functions for SDR

## Quantum Computing
- **Quantum SDK**
    - **[Q#](https://learn.microsoft.com/en-us/azure/quantum/)**: Microsoft's programming language and kit for quantum apps and algorithms
    - **[Qiskit](https://github.com/Qiskit/qiskit)**: IBM's open-source SDK for building, simulating, and running quantum circuits

## Scientific Computing
- **GPU Computing**
    - **[CUDA (Compute Unified Device Architecture)](https://docs.nvidia.com/cuda/)**: NVIDIA’s parallel computing platform for accelerated processing on GPUs
- **Numerical Computing**
    - **[MATLAB](https://www.mathworks.com/help/matlab/)**: numerical computing environment for math, simulations, and data visualization
